# Unitree R1 Панель оператора

Русскоязычная desktop-панель запускается из проекта:

```bash
cd /home/unitree/Unitree_Project/R1_Teleoperation
make operator-panel
```

На рабочем столе создан ярлык **Unitree R1 Панель оператора**. Панель использует
существующие Makefile-цели и скрипты, поэтому диагностика и safety gates остаются
общими с терминальным workflow.

По умолчанию включён `dry_run=true`, а live-кнопки выключены. Это можно изменить
на вкладке «Настройки» или в `config/operator_panel.json`. Включение live лишь
разрешает открыть safety-чеклист: токен commissioning, deadman и подтверждения
физической готовности панель не подставляет, а существующие fail-closed скрипты
проверяют их самостоятельно.

Кнопка «Проверить всё» последовательно запускает read-only проверки сети,
Ethernet/DDS камеры, robot/VR/ROS2 status. Вывод попадает во вкладку «Логи».
Долгие режимы не запускаются вторым экземпляром. STOP и KILL доступны сверху
всегда и вызывают `make robot-stop`/`make robot-kill`.

Mono-видео R1 запускается через `pov-vr`; `Stereo video (демо)` использует
подготовленный mock stereo источник. Настоящее stereo включать можно только после
появления двух физических видеопотоков.

## Первый запуск

1. Откройте ярлык **Unitree R1 Панель оператора** на рабочем столе или выполните
   `make operator-panel`.
2. На вкладке «Сеть и подключения» нажмите **Проверить всё** и дождитесь конца
   read-only диагностики. Исправьте красные ошибки; предупреждение о выключенном
   роботе допустимо, если нужен только интерфейс.
3. На вкладке «Видео глазами робота» нажмите **Запустить видео глазами робота**,
   затем **Открыть viewer в браузере**. Для проверки без робота используйте
   **Stereo video (демо)**.
4. После физической проверки положения робота откройте вкладку «Робот» и нажмите
   **Подготовить робота**. Для live это открывает safety-чеклист и затем вызывает
   существующий fail-closed `make robot-prepare`.
5. Во вкладке «Руки / ноги / teleop» сначала запустите **Повторять движения рук
   из VR**, затем отдельно **Включить движение ног**. Первый физический запуск
   выполняйте в slow/suspended профиле и держите KILL доступным.
6. Когда оба канала проверены, запускайте **Полный VR teleop**. Для software
   проверки без приводов используйте **Полный VR dry-run**.

Минимальный набор тестов панели и Robot POV:

```bash
python3 -m pytest -q                 # корневые smoke-тесты
make operator-panel-check
python3 -m pytest -q tests/test_operator_panel.py
PYTHONPATH=ros2_ws/src/r1_robot_pov:$PYTHONPATH \
  python3 -m pytest -q ros2_ws/src/r1_robot_pov/test
make operator-panel-smoke
```

Имена ROS-тестов сделаны уникальными по пакетам, поэтому общий запуск с явными
путями больше не получает `ImportMismatchError` из-за одинаковых `test_flake8.py`.
