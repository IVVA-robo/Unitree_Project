# Unitree R1 — короткая памятка для выставки

Проверенная схема: **Pico 4 Ultra и контроллеры — USB‑C → ноутбук — Ethernet → R1**.
Wi‑Fi и интернет для управления и видео не нужны.

## Перед запуском

1. Подключите USB‑C кабель данных к очкам и ноутбуку, Ethernet — к роботу.
2. Включите робота, очки и оба контроллера. Откройте ярлык **Unitree R1
   Панель оператора**. Не запускайте второй экземпляр панели.
3. Проверьте, что панель видит робота и очки, а видео уже появилось в очках.
4. Робот снят с зарядки, зона свободна, кабели не натянуты, Unitree Explore
   закрыт, аварийное отключение доступно, телефон роботом не управляет.
5. После появления видео можно выключить Wi‑Fi на ноутбуке и в очках. Связь
   с Codex после этого пропадёт — это нормально; панель продолжит работать.

## Рабочий запуск без Wi‑Fi

1. Нажмите **СТОЙКА** один раз и дождитесь статуса готовности и устойчивой
   стойки. Не нажимайте кнопку повторно во время подготовки.
2. Нажмите **RUN / ПОЛНОЕ УПРАВЛЕНИЕ** один раз. Дождитесь статуса RUN/готово;
   до этого не отклоняйте стики.
3. Для ходьбы используйте боковую кнопку **grip** контроллера и стики. Не
   путайте grip с курком под указательным пальцем.
4. Для паузы нажмите **LOCK / СТАТИЧНЫЙ РЕЖИМ**. Робот удерживает позу, видео
   должно остаться в очках. Возврат к управлению — только явным RUN.

Контрольный прогретый Wi‑Fi-off цикл 02.10.2026:

| Действие | Время |
| --- | ---: |
| СТОЙКА | 22,39 с |
| RUN | 31,91 с |
| LOCK | 1,49 с |

Холодный запуск после включения ноутбука или робота может быть дольше. Не
считайте задержку ошибкой и не нажимайте кнопку несколько раз подряд.

## Видео и переподключение

- **Открыть Robot POV** открывает уже работающий локальный видеопоток и не
  запускает второй сервер.
- **НАЙТИ И ПОДКЛЮЧИТЬ** сначала использует последнее рабочее Ethernet-соединение.
- **Переподключить всё** восстанавливает только потерянные компоненты; оно не
  переводит робота в RUN автоматически.
- Кнопки перекалибровки рук на выставочном экране нет — это сделано намеренно.

## Остановка и зарядка

1. В RUN сначала нажмите **LOCK**, дождитесь удержания позы.
2. Нажмите **СТОЙКА** и дождитесь статичного режима.
3. Нажмите **ZERO TORQUE / РАССЛАБИТЬ** только после устойчивой стойки и
   доступной аварийной остановки.
4. После полного снятия момента выключите робота штатной кнопкой и поставьте
   батарею на зарядку согласно инструкции R1.

## Если что-то пошло не так

- Не нажимайте одну кнопку многократно и не запускайте второй экземпляр панели.
- Если появилась ошибка, запишите её точный текст и остановите дальнейшие
  переходы.
- При немедленной угрозе используйте физическое аварийное отключение.
- После краткой потери USB или Ethernet управление не возобновляется само;
  дождитесь статуса и используйте явный RUN только после проверки зоны.
