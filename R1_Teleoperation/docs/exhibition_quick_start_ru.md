# R1: короткая памятка

1. Подключите робота и ноутбук по сохранённой проводной схеме. Откройте
   панель R1 и приложение на очках. Панель сама запускает read-only видео,
   находит актуальный Ethernet-адрес и адрес очков; вручную IP вводить не
   нужно. После этого включите робота и очки — это единственный момент,
   когда требуется их питание.
2. Освободите место вокруг робота. Наденьте очки, посмотрите прямо,
   держите оба контроллера у бёдер. Стики и кнопки отпущены.
3. Нажмите **«Режим управления» (RUN)** и дождитесь готовности.
   Первый запуск после включения проходит подготовку; не начинайте движение
   до готовности. Сохранённые позы рук заново записывать не нужно.
4. Левый стик — ходьба, правый — поворот. Во время ходьбы произвольное
   управление руками приостанавливается; после остановки возвращается.
5. Руки вперёд — вынос перед корпусом; контроллеры к глазам — сгибание
   локтей; вверх и в стороны — соответствующие записанные позы.
   Опущенные контроллеры возвращают руки к позе покоя.
6. **X слева** — вернуть руки в позу покоя. **B справа** — аварийная
   остановка. После B управление включается только явной командой RUN
   или снятием аварийной остановки в сервисном разделе.

На главном экране все рабочие кнопки запускают автоматический поиск и
восстановление нужных сервисов. **Переподключить всё** поднимет статический
контур, если сеанс ещё не был создан, а **Перекалибровать руки** сама включит
контур управления перед калибровкой. **ZERO TORQUE / РАССЛАБИТЬ** доступна
там же; нажимайте её только когда робот надёжно поддержан.

Видео в очках ищется через локальный discovery и автоматически переподключается
после смены Wi-Fi, DHCP или краткого обрыва. Если робот ещё выключен, приложение
может показывать ожидание камеры; после включения робота кадры появляются без
перезапуска приложения.

Руки и голова: предел скорости 1 рад/с. Это предел команды, а не обещание
постоянной фактической скорости каждого движения. Отдельное вращение
контроллеров пока не управляет вращением кистей/предплечий.

Чтобы отойти, используйте **«Статичный режим» (LOCK)**: ходьба остановлена,
поза удерживается, моторы продолжают работать. Для возвращения — RUN
со свежим трекингом и отпущенными стиками.

Перед перевозкой закрепите/поддержите робота и штатно выключите его.
LOCK не является выключением питания. Zero Torque используйте только
при надёжной опоре: робот перестаёт удерживать себя.
