# PC2: копирование заблокировано недоступностью

**На 30.09.2026 актуальная файловая система робота не получена.**
Пользователь уточнил, что PC2 не удаётся включить: прежняя проблема сохраняется,
SSH .164 недоступен. Причина отказа не установлена. Это не просто выключенный
компьютер, который оператор сейчас может включить.
Каталог не следует воспринимать как готовый backup PC2.

Сначала нужна отдельная диагностика/восстановление доступности PC2.
В рамках переноса ремонт, разборка или переустановка не выполнялись.
После восстановления, при подтверждённом Ethernet/SSH и без команд движения:

```bash
python3 Tools/GitHub/collect_robot.py \
  --host unitree@192.168.123.164 \
  --identity /home/unitree/.ssh/r1_pc2_ed25519 \
  --output /home/unitree/robot-export-НОВАЯ-ДАТА
```

Выходной каталог должен быть новым и вне публичного репозитория.
SSH host key должен быть заранее проверен; collector не отключает эту проверку.
Ключ остаётся на ноутбуке, его не публикуют.

Collector читает только перечисленные robot-related пути, сохраняет доступные
файлы и отчёт о наличии/доступности, не использует sudo, не меняет службы,
сеть и режим робота. Defaults включают VoiceAssistant, R1Service, проект/SDK,
ros2_ws и systemd-файлы voice-service. Это не инвентаризация всего диска.

Сначала read-only исследовать PC2 и расширить список --path при необходимости.
Вложенные unreadable-файлы/обрыв SSH означают незавершённый архив — не
публиковать его как успешный. Даже после успеха проверить содержимое,
секреты/лицензии, symlinks и фактический охват до загрузки в GitHub.
