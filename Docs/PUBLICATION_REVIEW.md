# Проверка перед публикацией — 30.09.2026

Проверялись файлы для Git и содержимое вложенных tar/zip/APK/wheel без
исполнения их кода. Tools/GitHub/audit.py — эвристика известных credential
форматов и опасных имён, не математическое доказательство отсутствия секретов.
Скрипт сообщает непроверенные полностью большие бинарные вложения.
Текстовые логи читаются целиком; исходники/отчёты дополнительно проверены на
литеральные password/token назначения.

Повторный проход охватил 5 309 файлов кандидатов. 57 крупных бинарных
вложений отмечены ограничением глубины/размера проверки; это в основном
библиотеки Unity/WebRTC в APK и архивах. Их контрольные суммы проверены,
но это не эквивалент анализа всего бинарного содержимого на секреты.

Выявлен маркер приватного ключа внутри стандартной библиотеки GnuTLS в PyAV.
Wheel **побайтово совпал с опубликованной контрольной суммой PyPI**:

- av-17.1.0-cp310-cp310-manylinux_2_28_x86_64.whl;
- SHA256 90c49bc9608377d01e82e747377505419a229464873341db18202d5dddecce5a;
- источник проверки: https://pypi.org/pypi/av/17.1.0/json;
- bundled av.libs/libgnutls-71454fd1.so.30.42.0;
- SHA256 aabbf4bb6fe30585ac0c704d4b505ab29a1b4b8dfb30ab2bf8928dc58ac63d66.

Это содержимое публичной vendor-библиотеки, не ключ ноутбука/робота. Бинарник
не изменяли. Предупреждение scanner оставлено видимым для повторной проверки,
не замаскировано общим исключением «не сканировать библиотеки».
Другие ранние совпадения оказались текстовыми маркерами PEM, документацией
SDK или фрагментами embedded-данных; сканер уточнён для полного начала PEM
и границ AWS-идентификаторов. Единственное password-назначение в отдельном
поиске исходников — тестовый 'do-not-log' в тесте маскирования секретов.

7 новых unit-тестов инструментов экспорта прошли без сети/ROS/робота:
исключение приватных путей, редактирование tokens, безопасная перепаковка,
восстановление GGUF и отказ при повреждении/перезаписи/path traversal,
mock SSH collector и различение маркера PEM от содержимого ключа.
Это не повторная функциональная приёмка робота и не полный regression run.

SHA256SUMS артефактов, потоковая сборка частей GGUF с проверкой исходного
SHA256 и git lfs fsck прошли. Обычных Git-объектов крупнее 50 MiB нет.
Новая документация/экспорт проходят diff --check. В импортируемых vendor
Unity-файлах и двух ранее созданных исходниках остаются whitespace warnings;
они не исправлялись ради сохранения исходного состояния рабочей версии.

Оригиналы не удалялись. Во время оформления/публикации физические команды
и перезапуски установленных служб не выполнялись.
