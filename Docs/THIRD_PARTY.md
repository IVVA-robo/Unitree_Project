# Сторонние компоненты

Репозиторий объединяет собственный код и материалы третьих сторон.
Единой новой лицензии на весь набор этим переносом не выдаётся.

- Unitree SDK/ROS: сохраняются LICENSE и вложенные notices поставщика.
- Pico SDK: см. SDK/Pico/Pico_SDK/LICENSE.md. Он содержит ограничения
  распространения; наличие SDK в Git не означает разрешения на перепубликацию.
  Дополнительный оригинальный SDK-архив не публикуется в этом переносе.
- Unity и пакеты: применяются условия Unity и лицензии каждого пакета.
  Unity Editor и Android toolchain не включены.
- scrcpy/ADB: сохраняются исходный установочный архив, SOURCE.txt и bundled LICENSE.
- NoMachine: проприетарный продукт; новые установщики остаются локально
  до проверки разрешения на распространение. Скрипты/документация сохранены.
  Пользовательские сессии/сертификаты/пароли не публикуются.
- Vosk и подготовительный voice-bundle: исходные архивы и вложенные notices
  сохраняются; модель vosk-model-small-ru-0.22 получена для офлайн-подпроекта.
- Gemma: веса GGUF — квантованный производный формат; условия Gemma, а не
  Apache-лицензия Python-кода библиотеки. Копия условий и Notice находятся
  рядом с manifest.json. Исходный источник конкретной квантовки по файлу
  не установлен; его происхождение не следует приписывать этому проекту.

Не использовать перенос для обхода условий сторонних поставщиков.
Лицензионно ограниченные локальные материалы перечислены в инвентаризации;
новому пользователю следует получить их из разрешённого источника.
