## Записи

Записаны вытянутые руки, руки у глаз, руки вверх и Т-поза. Для последних
трёх записей статусы подтверждают непрерывный трекинг обоих контроллеров.
В Т-позе получено 171–172 измерения на устройство за четыре секунды;
разброс положения контроллеров (95-й процентиль) — 5–8,5 мм.
Контроллеры находятся на разной высоте примерно на 3,3 см. Это измеренная
асимметрия позы, а не доказанная ошибка датчиков; искусственно выравнивать
её в программе по одной записи нельзя.

## Проверка преобразования

`audit_recorded_poses.py` использует действующую URDF, конфигурацию body proxy
и чистый IK. ROS и Unitree SDK не запускаются. Проверены статические цели
после установления фильтров. Реальные переходы между позами не записаны,
поэтому скорость и непрерывность физического движения этим не проверялись.

| Поза | Ошибка IK слева | Ошибка IK справа |
| --- | ---: | ---: |
| Вытянутые руки / нейтраль | 0 | 0 |
| Руки у глаз | 4,5 мм | 4,5 мм |
| Т-поза | 4,8 мм | 4,9 мм |
| Руки вверх | 92,5 мм | 87,2 мм |

Верхняя поза не проходит существующий порог ошибки 80 мм при расчёте
из номинальной нейтрали. Проверка с 14 начальными приближениями и увеличенным
числом итераций не дала точного решения: лучшие ошибки около 58 мм слева
и 87 мм справа. Это результат численной проверки текущего преобразования,
а не доказательство невозможности для робота поднимать руки вообще.
Случайные начальные приближения использовались только в расчёте;
такие суставные команды не отправлялись и для живого управления не выбирались.

Пределы суставов, масштаб, защиты и рабочий алгоритм не изменены ради
прохождения этих точек. Полное повторение верхней позы пока не подтверждено.
Вращения кистей также не откалиброваны: действующий IK использует
`orientation_weight=0.0`.

## Повторный запуск

Действующий exhibition startup заново фиксирует текущую позу контроллеров.
Это поведение не изменено. Сохранённый файл загружается IK, но не обеспечивает
сохранение сегодняшней нейтрали после автоматической перекалибровки RUN.
Для постоянного профиля ещё требуется согласовать этот механизм с запуском
и проверить привязку к фактическим суставам при включённом роботе.

Повтор расчёта: `PYTHONNOUSERSITE=1 /usr/bin/python3 logs/arms_calibration/audit_recorded_poses.py`.
